# צייד (Tzayad)

Search eBay for new products and see the final door-to-door price in Israel (item + shipping + VAT), and track how the cheapest price changes over time.

- Live site: GitHub Pages (`index.html` at the repo root).
- Backend: Supabase edge function `api` in project `imyhdvtdsotawkvyipbq` (source not in this repo yet).
- Tracked searches and price history are stored in the browser's localStorage (`tzayad.v1`); use the backup button to export/import.
